# Tillstone Land Solutions — website

Static site for **tillstone.land**. Everything the browser needs lives in `site/`.

```
site/
  index.html          MASTER FILE — all 5 pages' content (Home, Services, Experience, About, Contact)
  services/index.html ┐
  experience/…        │ generated by build.ps1 from index.html — don't edit these by hand
  about/…             │ (same content, different <title>/description/canonical)
  contact/…           ┘
  404.html            generated: home page marked noindex
  sitemap.xml         generated
  robots.txt          allows all crawlers, points at the sitemap
  favicon.svg         browser-tab icon (the layered-land logo)
  CNAME               custom domain for GitHub Pages
  assets/img/         photos (img-01 … img-20) + og-image.jpg (1200×630 social-share preview)
  assets/fonts/       Spectral + Public Sans (self-hosted, no Google Fonts call)
  assets/js/          page runtime + React (self-hosted, no CDN call)
pages.json            each page's URL, <title>, and meta description
build.ps1             regenerates the per-page files + sitemap + 404 from index.html and pages.json
serve.ps1             local preview server
```

## Editing with Claude

1. Open the Claude desktop app → Code → open this folder (`tillstone-site`).
2. Describe the change ("update Joey's bio", "swap the hero photo for the attached file",
   "add a fifth service"). Claude edits `site/index.html` / `site/assets/` / `pages.json`.
3. Claude runs `build.ps1` (regenerates the page folders), previews at http://localhost:8765,
   then commits and pushes — the host redeploys tillstone.land within about a minute.

**After any edit to `site/index.html` or `pages.json`, run:**
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

## How the page is built

`site/index.html` is one file. Page content sits inside `<x-dc> … </x-dc>`:

- `<helmet>` — fonts, base CSS, and the `#mobile-layout` responsive rules.
- One `<main data-screen-label="…">` block per page, wrapped in `<sc-if>` so only the
  page matching the URL path (`/`, `/services/`, `/about/` …) renders.
- The `<script type="text/x-dc">` at the bottom holds the small React component that
  picks the page from the URL, handles the photo-tab switchers, and the contact form
  (opens the visitor's mail client via `mailto:info@tillstone.land`).
- The `<!-- SEO:BEGIN … SEO:END -->` block in `<head>` is replaced per page by `build.ps1`.
  Below it, a JSON-LD `ProfessionalService` block describes the firm to search engines.

Styles are inline on each element. The responsive layer at the top of the helmet
targets those inline styles with attribute selectors, so if you change e.g. a
`font-size:72px` heading, check the matching `[style*="font-size: 72px"]` rule too.

Old `#services`-style links still work: the page rewrites them to `/services/`.

## SEO checklist (done)

- Real URL per page with unique title, description, canonical
- Open Graph / Twitter card tags + 1200×630 share image
- `robots.txt`, `sitemap.xml`, `404.html`, `lang="en"`, descriptive alt text
- Structured data (schema.org ProfessionalService, Raleigh NC)
- Mobile-friendly layout, no external requests, self-hosted fonts

**After launch:** add the site to Google Search Console (verify via DNS TXT record at GoDaddy),
submit `https://tillstone.land/sitemap.xml`, and create a Google Business Profile for the firm.

## Partner portraits

The four `<image-slot id="portrait-…">` elements on the About page are empty
placeholders. To fill one, drop a photo into `site/assets/img/` and replace the
`<image-slot …>` with an `<img>` of the same size/shape.
