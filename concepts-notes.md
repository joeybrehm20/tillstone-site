# Home page concepts: direction contracts (development only, never served)

Impeccable new-work, run by hand: the engine (concept-seed / serve-question) is not installed, so the
seven-candidate derivation and the five picks below were made manually. Code-led (no image generation).

Rut this category ships: aerial hero + serif headline + stat row + service cards (the live site).
Predictable opposite: dark tech gradient. Literal reading of the name ("strata / ground up"): allowed once at most; used zero times.

Seven candidates from the audience's world, by resonance:
1. Civil plan set / cover sheet (drawings)            -> concept 1
2. AIA G702/G703 draw request (lender paperwork)      -> concept 2
3. APWA utility locate marks on red clay (field)      -> concept 3
4. Construction entrance project sign (signage)       -> concept 4
5. USGS 7.5' topographic quadrangle (cartography)     -> concept 5
6. Recorded survey plat, metes and bounds (drawings, near-duplicate of 1)
7. Soil boring log (literal strata reading, spent)

## 1 Plan Set
THESIS: the firm presents itself the way its work is delivered, as a sealed drawing sheet; refuses the aerial hero.
OWN-WORLD: plotter-white sheet on drafting-table gray, black line work, screened gray, one revision red. Archivo condensed titles, Chivo Mono for annotation and dimensions.
STORY: sheet title block names the firm; general notes are the services; site data is the track record; details are the projects.
FIRST VIEWPORT: full sheet frame, title block on the right edge, headline as the drawing title, a real site plan in a viewport with north arrow and graphic scale, sheet index as nav.
SIGNATURE: revision clouds draw themselves around the site data.

## 2 Draw Request
THESIS: lenders read pay applications all day; Tillstone speaks their form. Refuses marketing layout.
OWN-WORLD: form paper, green-bar ledger bands, black print, typed entries, one rubber-stamp red.
STORY: application header -> schedule of values (services, led by) -> project ledger -> certification signed by four partners.
FIRST VIEWPORT: G702-style header boxes, the hook typed into the "project" field, primary action as "Submit an application".
SIGNATURE: CERTIFIED stamp lands on the certification block.

## 3 Locate Marks
THESIS: know what is in the ground before capital goes into it. Refuses the clean corporate ground.
OWN-WORLD: drenched NC red clay, APWA code colours as the only palette (white, pink, blue, yellow, orange), sprayed marks.
STORY: the colour-code key is the services legend; projects are marked-out parcels; the call is "call before you dig".
FIRST VIEWPORT: clay field, sprayed white outline marking the headline, a pink survey flag line, primary action as the 811-style ticket.
SIGNATURE: marks spray on (stroke draw with rough edge).

## 4 Project Sign
THESIS: every project sign lists owner, contractor, builder, lender; the partners have held every line.
OWN-WORLD: guide-sign green, retroreflective white, Overpass (Highway Gothic lineage), rounded sign panels with inset border.
STORY: entrance sign -> roster of seats -> distance-sign track record -> projects as exit tabs -> contact.
FIRST VIEWPORT: one large sign panel on posts; firm name, headline, roster; action on a separate small tab sign.
SIGNATURE: panels mount (rise and settle) as they enter.

## 5 Topo Quad
THESIS: land people read terrain; the firm is presented as a map of where it has worked. Refuses photography-led hero.
OWN-WORLD: USGS white with brown contours, blue hydrography, woodland green tint, red roads, black collar lettering; hydro labels in italic.
STORY: map collar names the firm; projects plotted as benchmarks; legend holds services and track record; adjoining-quads index is the project list.
FIRST VIEWPORT: generated contour map full-bleed inside a map collar with coordinates, title block and scale bar.
SIGNATURE: contours draw in; cursor crosshair reads coordinates.

FINISH: these are concepts for a direction choice. The chosen one gets the full build, finish review, and DESIGN.md.
